# dpf-preinspect

Vision pre-inspection and downstream-outcome prediction for used diesel particulate filters (DPFs) arriving at a cleaning and remanufacture line.

> **All data in this repository is synthetic and generated locally.** Results demonstrate the method, not real-world performance.

Built independently to explore the problem described in the Eminox–University of Lincoln KTP advert; not affiliated; synthetic data only.

## Status

Work in progress. See `docs/project_plan.md` for the delivery log.

## Quickstart

```bash
make setup     # virtual environment and dependencies
make demo      # synthetic data, models, evaluation, validation, reports
make api & make app
```
